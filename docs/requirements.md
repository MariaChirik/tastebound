# Вимоги до Tastebound (скорочено)

## Основні функції
1. Фільтри за алергенами та дієтою.
2. Спільне замовлення за посиланням.
3. Реалістичний час доставки (відстань + завантаженість кухні).
4. Відстеження замовлення та кур'єра в реальному часі.
5. Оцінка страв і блок рекомендацій.
6. Кабінет ресторану: стоп-лист і режим перевантаження.

## Нефункціональні вимоги
- До 500 одночасних користувачів, до 50 замовлень на хвилину.
- Відповідь API при оформленні замовлення - до 1,5 с.
- Доступність не менше 99%.
- Збій сповіщень або рекомендацій не блокує оформлення замовлення.
- Паролі зберігаються лише як хеші, платіжні дані не зберігаються, усі з'єднання - HTTPS.

# frontend/

Вебінтерфейс Tastebound. Статичний застосунок без збирання: HTML, CSS і ES-модулі в браузері.

## Структура

- `index.html` — розмітка і навігація;
- `css/styles.css` — стилі;
- `js/logic.js` — чиста логіка (кошик, фільтри, статуси, перевірка оцінок), без DOM;
- `js/api.js` — клієнт API, шляхи відповідають шлюзу `deploy/gateway/nginx.conf`;
- `js/app.js` — інтерфейс: каталог, кошик, оформлення, замовлення, оцінки, акаунт.

## Що вміє

- каталог з фільтром за дієтою; обмеження з харчування зберігаються в профілі і приховують небезпечні страви;
- кошик і оформлення: створення замовлення, потім оплата в тестовому режимі; якщо оплата не пройшла, замовлення скасовується;
- статус замовлення з Tracking (опитування кожні 5 с) і скасування до початку приготування з поверненням оплати;
- оцінки страв і блок «Вам сподобається».

## Тести

```
cd frontend
node --test
```

Тести покривають логіку та клієнт API. Інтерфейс перевіряється вручну в браузері після `docker compose up`.

## Обмеження поточної версії

- Order не прив'язує замовлення до користувача, тому список «Мої замовлення» зберігається на пристрої.
- Сервіси не перевіряють токен; він зберігається, але ще не використовується.
- Статуси Order і Tracking мають різні словники; інтерфейс показує актуальніший із двох.
